傅里叶反变换合成信号：遍布 ω 轴的复指数 ejωt 的线性加权积分，权重 = F(jω)dω/2π

f(t) = (1/2π)∫−∞+∞ F(jω) ejωt dω = limΔω→0 Σn F(jnΔω)·(Δω/2π)·ejnΔω t  —  每个分量的权重 = F(jnΔω)·Δω/2π（无穷小），矢量链端点 = f(t)

信号与频率粒度（主角滑条：Δω）

反变换把 f(t) 写成全体频率复指数 ejωt 的「连续和」：每个频率的权重 = F(jω)dω/2π。计算时以 Δω 离散化，共 N=⌊Ω/Δω⌋ 个分量。把 Δω 拖小：谱线变密、权重按 Δω 比例变矮、复平面矢量链的段缩到肉眼难辨（用放大镜看），黎曼和贴紧积分；代价是和式以 Tr=2π/Δω 为严格周期（黄括号），Tr 太小时周期副本 Σk f(t−kTr) 会走进观测窗（红括号）。

播放（t 驱动复平面矢量链）

播放时 t 在观测窗 ±Tw 内回绕（1× 时 8 s 一圈）；t 滑条可在整轴 ±Xw 内定位；也可直接在下方时域面板按住拖动刮擦。黎曼和以 Tr=2π/Δω 为严格周期，窗外的部分是周期副本。

三块面板怎么看

左上：复平面。vn=F(jnΔω)(Δω/2π)ejnΔω t（n=−N…N）首尾相接成链，端点 = 合成 s(t)；链段颜色 = 该分量 t=0 初相位 arg F(jnΔω)（谱线、3D 栅栏同色）；红向量 = s(t)，它在 Re 轴上的投影就是时域曲线的高度。Δω 小时段长缩到肉眼难辨 —— 右上圆放大镜把鼠标附近的链放大 ×g 画出来。
右上：频谱。谱线 = 权重 |F(jnΔω)|·Δω/2π（随 Δω 成比例缩矮 = 无穷小），灰包络 = |F(jω)|·Δω/2π；切「原始 |F(jω)|」看包络本身不随 Δω 变。悬停谱线 → 链上同色段白色加粗；点击谱线 → 静音该分量。勾「3D 频谱栅栏」后右上改画三维视图：站在 σ=0 平面里的同色栅栏（茎高 = 权重）加灰包络幕布，水平面是 jω 轴与 σ 轴，在面板内按住拖动可旋转视角（yaw/pitch）。σ 轴是给拉普拉斯反变换预留的空槽位：将来整排栅栏沿 σ 滑动、脚下铺出 |X(σ+jω)| 高度曲面，就是拉普拉斯页的舞台。点击静音只在 2D 模式生效；双击恢复全部静音两种模式都生效。
下：时域。彩色 = 黎曼和合成 Re s(t)（以 Tr=2π/Δω 严格周期，即泊松 Σk f(t−kTr)）；灰虚线 = 理想 f(t)。红括号 = 观测窗 ±Tw，黄括号 = 一个黎曼周期 Tr；绿虚线 = t=0 原点；纵轴 = Re s(t)。按住拖动可刮擦 t。
