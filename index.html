本地运行

纯静态站点，没有任何构建步骤。直接双击本文件即可打开：卡片链接都指向具体的 index.html，所以在 file:// 下同样能一层层点进去。

若浏览器对 file:// 有限制，可在本目录启动一个静态服务器，例如 python -m http.server，再访问 http://localhost:8000/。

后续可视化

新增一个案例 = 在本仓库新建一个子目录，再在页面顶部的卡片区加一张卡片，无需改动已有子项目。

两个子项目内部一律使用相对路径引用资源，因此放在任意子路径下都能正常工作——这正是它们能被整体搬进子目录、而页面互不干扰的原因。

本仓库由两个独立的可视化工程合并而成，两套页面内部的相对路径与跳转关系保持原样。
旧地址 fourier_transform.html 与 laplace_transform.html 会自动跳转到 ft_laplace/ 下的对应页面。
