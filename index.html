Fourier Transform & Laplace Transform

The winding machine: wrap the signal around a circle, watch the center of mass, and read the frequency content out of the wobble. Add a real exponent σ and the same machine explains the σ envelope, poles and the region of convergence. Two single-file pages, plus a Python notebook version.

Fourier Series & Inverse Transforms

One storyline: harmonic summation of periodic signals → as T→∞ the spectral lines crowd together and become the Fourier transform → Riemann-sum synthesis of the inverse Fourier transform → the inverse Laplace transform with e(σ+jω)t swapped in. Every page shows the synthesis as a chain of head-to-tail vectors on the complex plane.

Run locally

A purely static site with no build step. Just double-click this file to open it: the card links point to concrete index.html files, so you can click your way down even under file://.

If your browser restricts file:// pages, start a static server in this directory, e.g. python -m http.server, then visit http://localhost:8000/.

Future visualizations

Adding a new case = create a new subdirectory in this repository and add a card to the card row above — no need to touch the existing sub-projects.

Both sub-projects reference their resources with relative paths only, so they work when served from any sub-path — which is exactly why they could be moved into subdirectories wholesale without the pages interfering with each other.

This repository merges two formerly independent visualization projects; the relative paths and cross-links inside each set of pages are unchanged.
The old addresses fourier_transform.html and laplace_transform.html automatically redirect to the corresponding pages under ft_laplace/.
