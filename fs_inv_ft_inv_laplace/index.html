信号与系统 · 傅里叶 / 拉普拉斯可视化合集

一条主线：信号 = 复指数信号的线性组合。从周期信号的傅里叶级数（离散谐波求和）， 到周期 T→∞ 时谱线变密、系数变矮而过渡为傅里叶变换（连续积分）， 再到把积分换到 s = σ+jω 线上得到拉普拉斯反变换。每一页都用复平面上首尾相接、 旋转伸缩的向量链展示"合成"这件事，下方同步显示该向量链在实轴上的投影随 t 的变化。

① 傅里叶级数线性叠加 周期信号 = 谐波关系的复指数信号之和。复平面内若干旋转基向量加权首尾相接，端点轨迹的实部即波形。 ② 从傅里叶级数到傅里叶变换 T 增大 → 谱线变密、Fₙ 变矮：离散和如何在视觉上过渡为 (1/2π)∫F(jω)e^{jωt}dω。 ③ 傅里叶反变换合成信号 非周期信号 = 遍布 ω 轴的 e^{jωt} 的加权积分。黎曼和向量链、频谱谱线与三维 s 平面视图联动。 ④ 拉普拉斯反变换合成信号 把合成基换成 e^{(σ+jω)t}、权重换成 X(σ+jω)：旋转之外还有伸缩的向量链。

本地运行

纯静态站点，无需构建：直接双击 index.html 用浏览器打开即可。

若浏览器对 file:// 有限制，可把本目录作为静态根启动一个本地服务器，例如 python -m http.server，然后访问 http://localhost:8000/。
