信号、收敛横坐标 σ 与频率粒度（主角滑条：Δω 与 σ）

反变换把 f(t) 写成 s 平面竖线 Re s=σ 上全体复指数 est 的「连续和」：权重 = X(s)ds/2πj。σ 必须落在收敛域 ROC（s 平面绿色带）内：因果信号 σ > 最左极点，双边信号夹在两极点之间。基向量 vn 一面旋转（ejωt）一面整体呼吸（eσt）；σ=0 就退化为傅里叶反变换。计算以 Δω 离散化，共 2N+1 个分量。把 Δω 拖小：谱线变密、权重按 Δω 比例变矮、矢量链段缩到肉眼难辨（用放大镜看），黎曼和贴紧积分；代价是和式以 Tr=2π/Δω 为严格周期，且副本权重为 e−σkTr：σ>0 压低未来副本、但把过去副本放大 e+σTr 倍。

播放（t 驱动复平面矢量链）

播放时 t 在观测窗 ±Tw 内回绕（1× 时 8 s 一圈）；t 滑条可在整轴 ±Xw 内定位；也可直接在下方时域面板按住拖动刮擦。eσt 随 t 变化：σ>0 时整条链随时间膨胀、σ<0 收缩、σ=0 只旋转。

三块面板怎么看

左上：复平面。vn=X(σ+jnΔω)(Δω/2π)e(σ+jnΔω)t（n=−N…N）首尾相接成链，端点 = 合成 s(t)；红向量 = s(t)，它在 Re 轴上的投影就是时域曲线的高度。所有 vn 共享呼吸因子 eσt：播放时整条链一边转一边胀缩。Δω 小时段长缩到肉眼难辨 —— 右上圆放大镜把鼠标附近的链放大 ×g 画出来。
右上：s 平面。× = 极点、○ = 零点、绿色竖带 = ROC；青色竖线 = 积分路径 Re s=σ（滑条可调，出 ROC 即不收敛）。横谱线 = 权重 |X(σ+jnΔω)|·Δω/2π（随 Δω 成比例缩矮 = 无穷小），灰包络 = 连续 ω 的 |X|·Δω/2π；切「原始 |X|」看包络本身不随 Δω 变。悬停谱线 → 链上同色段白色加粗；点击谱线 → 静音该分量。
下：时域。彩色 = 黎曼和合成 Re s(t)（以 Tr=2π/Δω 严格周期，副本权重 e−σkTr）；灰虚线 = 理想 f(t)；粉虚线 = 副本鬼影 e−σkTrf(t+kTr)。红括号 = 观测窗 ±Tw，黄括号 = 一个黎曼周期 Tr。按住拖动可刮擦 t。
